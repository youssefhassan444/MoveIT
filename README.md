# MoveIt — Delivery App for Egypt

MoveIt is a production-ready delivery application built for the Egyptian market, connecting customers who need items moved with drivers who have the right vehicle for the job. All prices are in EGP (Egyptian Pounds), with Cairo as the default region.

## Prerequisites

- Flutter SDK 3.22+ (Dart 3.9+)
- Firebase CLI (`npm install -g firebase-tools`)
- FlutterFire CLI (`dart pub global activate flutterfire_cli`)
- Android Studio (with Android SDK, API 34)
- A Firebase project (Spark/free plan is sufficient for development)

## Setup Steps

### 1. Clone & Install Dependencies

```bash
git clone <repo-url>
cd MoveIT-Flutter-V2
flutter pub get
```

### 2. Connect to Firebase

```bash
firebase login
flutterfire configure
```

This will generate/overwrite `lib/firebase_options.dart` and download `android/app/google-services.json`.

### 3. Google Maps API Key

Get an API key from [Google Cloud Console](https://console.cloud.google.com/apis/credentials) with Maps SDK for Android enabled.

Insert it in `android/app/src/main/AndroidManifest.xml`:

```xml
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_ACTUAL_KEY_HERE"/>
```

### 4. Set Firestore Security Rules

Copy the security rules from `lib/core/constants/firestore_schema.dart` and paste them into:
- Firebase Console → Firestore Database → Rules
- Firebase Console → Storage → Rules

### 5. Run

```bash
flutter run
```

### 6. Build Release APK

```bash
flutter build apk --release
```

Output: `build/app/outputs/flutter-apk/app-release.apk`

## Architecture Overview

```
lib/
  main.dart                          — Entry point, ProviderScope, MaterialApp.router
  firebase_options.dart              — Generated by flutterfire configure
  core/
    theme/app_theme.dart             — Navy/SkyBlue/Orange brand theme
    router/app_router.dart           — go_router routes with auth redirect
    constants/
      app_constants.dart             — Cairo coords, EGP formatting, vehicle types
      firestore_schema.dart          — Firestore schema + security rules docs
  features/
    auth/
      auth_wrapper.dart              — Streams auth state, routes by role
      login_screen.dart              — Email/password + role toggle
      signup_screen.dart             — Full registration with vehicle type
    customer/
      customer_shell.dart            — 4-tab nav (Post Job, My Jobs, History, Profile)
      post_job_screen.dart           — 5-step job posting wizard with maps
      customer_jobs_screen.dart      — Firestore stream of customer's jobs
      customer_job_detail_screen.dart — Live tracking map + status timeline
    driver/
      driver_shell.dart              — 3-tab nav (Job Board, History, Profile)
      job_board_screen.dart          — Filtered pending jobs, transaction-based accept
      active_job_screen.dart         — Status transitions, live location tracking
    shared/
      profile_screen.dart            — Photo upload, earnings, logout
      trip_history_screen.dart       — Searchable trip history
  models/
    user_model.dart                  — UserModel with Firestore serialization
    job_model.dart                   — JobModel with piastres pricing
    tracking_model.dart              — TrackingModel for real-time location
  services/
    auth_service.dart                — Firebase Auth + Riverpod providers
    location_service.dart            — Geolocator position streaming
    notification_service.dart        — FCM + local notifications
```

**State Management:** flutter_riverpod — providers for auth state, user doc, routing

**Navigation:** go_router — declarative routing with auth guard, nested routes

**Data:** Cloud Firestore — real-time streams, transaction-based job acceptance

**Monetary:** All values stored as int piastres (1 EGP = 100 piastres), displayed as "X.XX EGP"
